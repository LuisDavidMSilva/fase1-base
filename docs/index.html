Projetos

Projeto 1: Site de Portfólio

Desenvolvi esse site de portfólio para mostrar meus trabalhos e habilidades em desenvolvimento de software...

Nesta seção dos site terá o front-end dos dois projetos (que ainda são cli) que desenvolvi: uma calculadora e um jogo da adivinhação em JavaScript. Exemplos simples da minha capacidade.

Também tenho esse outro site para mostrar os bastidores do meu homelab, além de manter como documentação para consulta futura. Você pode conferir ele aqui: Homelab.

Projeto 2: Calculadora

Desenvolvi uma calculadora simples em JavaScript para praticar minhas habilidades de programação. A calculadora suporta operações básicas como adição, subtração, multiplicação e divisão. O usuário pode inserir os números e a operação desejada com (+, -, *, /).

Projeto 3: Jogo da Adivinhação

Criei um jogo da adivinhação em JavaScript onde o usuário tem que adivinhar um número gerado aleatoriamente entre 1 e 10.

Há um certo número de tentativas para adivinhar o número correto, que são informadas a cada tentativa mal sucedida. Caso as tentativas se esgotem, o jogo termina.

Projeto 4: Taskboard

Desenvolvi um taskboard simples usando Vite e React para organizar minhas tarefas diárias. O taskboard permite criar, excluir e mover tarefas entre diferentes etapas.
