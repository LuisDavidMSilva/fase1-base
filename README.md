# Plano Dev Full Stack: Fase 1 - Base

Senti que precisava voltar a estudar programação de fato, pedi ao Claude para gerar e estruturar um plano de alguns meses para cobrir o básico para quem já viu um pouco de quase tudo.
Neste repo `Fase 1 - Base` tem:

* Uma calculadora e um jogo de adivinhaçao simples em JavaScript feitos que rodam em cards na mesma página.

* Uma lista de tarefas básica com um pouco de css e JS.

* Um página de portfólio com design premium, com seções sobre, projetos, certificados e contato. Nela serão adicionadas as competências e os projetos que virão por aí.
